# 王陈说写作规范（模式四硬约束）

本文件是"嵌入写作规范润色"模式的判定依据。润色时逐条核对，优先修正前三项高频问题。规范的用意是让文本更可信、更耐读、更具辩证厚度，而非套用固定腔调。

## 1. 标点约束

- 不使用破折号（——）。解释、补充说明改用逗号，或另起一句。
- 连续列举不用空格短横代替标点。

## 2. 句式约束

- 不使用"不是……而是"及其近似翻案句式（"与其说……不如""没那么……而是""问题的关键不在……而在"）。
- 该句式常以否定一方来抬高另一方，会掩盖复杂性。改为并列呈现两面，或先承认再推进。
- 减少"X：Y"式的机械解释堆叠。优先用连贯叙述带出因果，仅在确实需要分项时列举。

## 3. 辩证视角

- 避免绝对化判断（"彻底""完全""必然""所有"）。给出范围、条件或概率。
- 区分事实与观点，观点明确标注为推断或建议。
- 凡存在相反证据或局限，至少一句话点出，体现权衡。

## 4. 来源标注

- 涉及外部事实、数据、研究结论时，标注来源。格式：机构或作者 + 文献/报告名 + 时间（如有）。
- 示例：来源：世界卫生组织《关于身体活动有益健康的全球建议》。
- 来源未知或无法核实，明确说明"暂未找到可核实来源"，不得编造。

## 5. 表达克制

- 除非用户明确要求，正文不出现 emoji。
- 不使用空泛口号与情绪化超级词（"惊人的""完美的""颠覆性的"）。用量化或具体描述替代。
- 标题与正文保持一致语气，不靠感叹号制造紧迫感。

## 6. 核查清单（润色后自检）

- [ ] 无破折号
- [ ] 无"不是……而是"类翻案句式
- [ ] 无绝对化用词
- [ ] 外部事实均有来源标注
- [ ] 无多余 emoji 与空泛口号
- [ ] 辩证视角已体现，原意未丢失
